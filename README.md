### 🧠 How It Works

### ♥ Main Chat Button

QuickSymbols adds a heart button near the game's Chat and some other native windows.
Clicking the button opens the symbol list. Clicking it again closes the list.
The main button position can be changed in the config: _(Or manualy draging it)_

| Option | Behavior |
| --- | --- |
| `Left of Chat` | Places the button on the left side of the chat controls |
| `Right of Chat` | Places the button on the right side of the chat controls |
| `Keybind Only` | Hides the button and only uses the keybind popup |

---

### ✨ Symbol Picker Popup

The popup contains several tabs for different types of symbols.

| Tab | Purpose |
| --- | --- |
| Home | General symbols and favorites |
| Numbers | Number-related symbols |
| Letters | Letter/alphabet-related symbols |
| Common | Commonly used symbols |
| Others | Extra symbols |
| Time | Time/date-related symbols |
| Custom | User-created entries from the config window |

---

### ⭐ Favorites

- Hold `CTRL` and click a symbol to add it to favorites.
- Hold `CTRL` and click a favorite again to remove it.

Favorite symbols appear in the `Favorites` section at the top of the list and are shared between all tabs/keybind-popup.

---

### 🧩 Custom Entries

Custom entries are managed through the config window opened with:

```txt
/qsconfig
```

Custom entries can be used for:

| Type | Example |
| --- | --- |
| Single symbols | `★` |
| Pre-made texts | `Welcome!` |
| Decorative pieces | `✦ ─ ✦` |

The Custom Entries input also supports opening the symbol list through the configured keybind.

| Command | Action |

| `/qsconfig` | Opens the QuickSymbols configuration window |

---

### 🎨 Config Options

| Option | Description |
| --- | --- |
| Open symbol list without button | Use the configured keybind to open |
| Button position | Changes the main Chat button placement |
| Use Dalamud theme | Uses Dalamud colors for the popup instead of FFXIV theme |
| Background opacity | Adjusts popup and symbol background opacity |
| Close popup on lost focus | Closes the popup when clicking outside of it |
| Custom Entries | Adds, edits or removes custom entries |

<a id="ipc-integration"></a>

### 🔌 IPC Integration

QuickSymbols exposes an IPC surface for other plugins that want to open the picker for their own ImGui inputs.

| Endpoint | Type | Purpose |
| --- | --- | --- |
| `QuickSymbols.GetVersion` | Function | Returns the current IPC version |
| `QuickSymbols.GetHotkey` | Function | Returns the configured QuickSymbols hotkey |
| `QuickSymbols.WatchInput` | Function | Marks another plugin's input as active for the QuickSymbols keybind |
| `QuickSymbols.OpenPicker` | Function | Opens the picker for a specific owner key |
| `QuickSymbols.ClosePicker` | Function | Closes the picker for a specific owner key |
| `QuickSymbols.SymbolSelected` | Event | Sends the selected symbol back to the owner plugin |

See [IPC.md](https://github.com/LatencyBryer/QuickSymbols/blob/main/IPC.md) for the full integration guide.
